# Plan de implementación

## MVP verificable

1. **Perfil**: coordenadas, suelo conocido/desconocido, rotación actual y prioridades del productor.
2. **Evidencia**: clima NASA POWER y datos locales con fechas, escala y advertencias visibles.
3. **Comparación**: tres rotaciones; reglas documentadas y revisadas localmente; mostrar razón, beneficios posibles, faltantes y riesgos.
4. **Escenarios**: lluvia −20 % y calor adicional con supuestos explícitos. Es un análisis de sensibilidad, no pronóstico.
5. **Presentación**: calendario y mapa solo cuando existan series y geometrías para sustentarlos.

## Reparto sugerido (4–5 personas)

- Datos NASA y procedencia.
- Suelos/cultivos y validación agronómica.
- API y motor explicable.
- Web, mapa y accesibilidad.
- Integración, pruebas y presentación (compartida si son cuatro).

## Criterios antes de mostrar una recomendación real

- Fuente y unidades de cada entrada visibles.
- Reglas y pesos editables o documentados, con revisión agronómica.
- Faltantes y resolución de datos visibles por campo.
- Comparación contra la rotación actual y revisión de riesgos.
- Pruebas con casos contrastantes y revisión humana.

## Decisiones abiertas

- Región y cultivos objetivo en Uruguay.
- Fuente de suelos y autorización de uso.
- Licencia del código.
- Despliegue y tratamiento de ubicaciones precisas de productores.
